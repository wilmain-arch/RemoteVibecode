# Новые инструменты чата и управление задачами

- В APK добавлены поиск по текущему чату, план и цель, очередь Desktop, операции с проектами и Git, архивирование, ветвление и откат истории, а также просмотр изменений и действий по ходу.
- Агент ПК обновлён для новых операций управления чатом, рабочей папкой и Git.
- Поиск ограничен открытым чатом. Создание настоящих субагентов пока не поддерживается.
- Корректировка записи нативной очереди Desktop и согласование её внешнего удаления ограничены. Живой модельный review не тестировался.

Обновите агент ПК и Android-приложение по [порядку обновления](https://github.com/wilmain-arch/RemoteVibecode/blob/main/docs/UPDATING.md).
