# Исправления меню субагентов

- Устранена возможная взаимная блокировка моста при одновременной отправке сообщения и уточнения субагенту.
- После восстановления связи ранние сообщения субагента доступны через корректный курсор истории.
- Черновики сохраняются при переключении между субагентами. Модель видна в заголовке открытого чата.
- Добавлены счётчик и ограничение 32 000 символов, а итоговые события подписаны «Итог работы».
- Обновление истории не прокручивает вниз пользователя, читающего старые сообщения.
- CI проверяет ошибки Python и регрессии блокировок; Windows собирается для PR с изменениями агента или моста.

Обновите APK и агент ПК. Ретранслятор менять не требуется.
