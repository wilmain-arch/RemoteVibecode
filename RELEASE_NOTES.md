# Меню субагентов

- В чате появилась кнопка «Субагенты»: список агентов текущей задачи, их роли, статусы и поручения.
- Открывается история каждого агента с ходом работы, сообщениями и изображениями. Список обновляется автоматически.
- Можно отправить уточнение работающему агенту или новую задачу свободному. Прерывание текущей задачи требует подтверждения.
- Если Codex Desktop не разрешает прямой ввод агенту, приложение объясняет ограничение.

Обновите APK и агент ПК. Ретранслятор менять не требуется. Возможности управления зависят от установленной версии Codex Desktop.
