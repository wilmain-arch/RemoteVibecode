# RemoteVibecode 0.4.1

## Обновления внутри приложения

- В Android и агентах появился раздел «Обновления»: проверка вручную и автоматически раз в сутки.
- Доступны описание изменений, скачивание с прогрессом и отмена.
- Манифест подписан отдельным ключом выпуска; файлы проверяются по SHA-256. APK дополнительно проверяется по версии, package ID и сертификату установленного приложения.
- Android открывает системный установщик. Разрешение установки из этого источника запрашивается только по нажатию «Установить».
- Windows устанавливает обновление отдельным процессом, сохраняет прежний EXE и восстанавливает его, если новая версия не запускается.
- Arch обновляется через pacman с системным запросом прав администратора; после отмены или ошибки агент запускается снова.
- Установка агента ждёт завершения задач и очереди сообщений. Настройки, привязка телефона и пользовательские файлы сохраняются.
- Ошибка проверки обновлений не влияет на соединение с ПК и работу чата.

## Первое обновление

Чтобы появилась эта функция, установите APK 0.10.0 и агент 0.2.1 обычным способом. Следующие версии можно устанавливать из раздела «Обновления». Ретранслятор менять не требуется.

Сборки Windows и Arch проходят CI. Сценарий установки Windows с откатом требует проверки на реальном Windows ПК; Linux установка требует работающего графического агента polkit.
