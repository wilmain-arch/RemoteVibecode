# RemoteVibecode 0.6.1

- В APK добавлена постраничная загрузка файлов проекта и поиск по именам во всей открытой папке. Скрытые и служебные файлы можно включить отдельно.
- Внешние и недоступные символические ссылки отмечаются и не открываются.
- APK и агент сверяют возможности протокола. При неизвестной совместимости приложение показывает подсказку обновить агент.
- Очередь сверяется с Desktop и историей чата. При неопределённом результате сообщение не отправляется повторно автоматически.
- Обновлены иконки приложения в стиле «Фокус».

Ограничения: атомарная корректировка нативной очереди Desktop недоступна; общий поиск по всем чатам не добавлен.

Скачайте APK и пакет агента из этого релиза. Для установки следуйте [порядку обновления](https://github.com/wilmain-arch/RemoteVibecode/blob/main/docs/UPDATING.md).
