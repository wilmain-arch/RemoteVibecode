# RemoteVibecode 0.9.12

Загрузите приложение для Android, агент для Windows или Arch Linux и пакет ретранслятора для своего сервера Debian 13 или Ubuntu 26.04.

Порядок установки и настройки: [README](https://github.com/wilmain-arch/RemoteVibecode#readme). Контрольные суммы файлов — в `SHA256SUMS.txt`.

Android-приложение теперь использует подключение через собственный ретранслятор как основной вариант. APK подписан отладочным ключом.

Список берёт проекты из Codex app-server и показывает их в заданном порядке. Чаты без проекта идут после проектов.

Экран проектов использует единый вид строк. Текущий проект определяется по привязке чата, настройки перенесены в конец списка.

В списке чатов добавлена кнопка удаления с подтверждением. Активную задачу и чат с сообщениями в очереди удалить нельзя.

Добавлено перемещение чата в существующий проект или раздел «Без проекта». В чате появилась кнопка перехода к последнему сообщению. При открытии клавиатуры лента прокручивается так, чтобы последнее сообщение оставалось над полем ввода.
