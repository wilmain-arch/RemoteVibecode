# RemoteVibecode 1.1.0

## Новое

- Изменения файлов прямо в чате: раскрываемый diff, номера старых и новых строк, счётчики добавлений и удалений.
- Копирование diff и сохранение изменений отдельного файла или всей задачи в `.patch`.
- Экспериментальный гостевой доступ: приглашения, отдельные чаты и рабочая область, отзыв доступа, независимые квоты на 5 часов и неделю.
- Общие проекты и чаты с правами доступа; изменения гостя остаются в копии до подтверждения владельцем.
- Гостевой чат использует общий интерфейс «Фокус»: темы, файлы, изображения, выбор модели и усилия.

## Исправления

- Сохранение гостевой сессии при возврате назад и открытие сохранённых подключений.
- Цвета управления гостями и гостевого чата в светлой и тёмной темах.
- Ложное определение открытого Desktop и гонка гостевого запуска при подготовке перезапуска агента.
- Устойчивость интерфейса на компактных экранах и диагностика Android в CI.

## Обновление

Обновите APK и агент. Привязка и данные сохраняются. Ретранслятор остаётся версии **1.0.0** — менять установленную версию для этого обновления не требуется. Перед перезапуском агента дождитесь завершения задач и очереди.

## Ограничения

Гостевой запуск пока доступен только на Linux с Bubblewrap и требует закрытого окна Codex Desktop. Windows-агент продолжает обслуживать основной чат. Гостю пока недоступны субагенты, Git/review, планы и корректировка очереди.

При неизвестном исходе гостевой задачи очередь ожидает согласования расхода владельцем: автоматического повторного запуска нет. Квоты измеряются по доступным счётчикам Codex; точность ограничена округлением и внешней активностью аккаунта.

Diff отражает опубликованные изменения задачи, а не текущий Git diff. Изменения через shell без события `fileChange` не реконструируются. Сокращённый diff не экспортируется. Визуальное оформление просмотрено на телефоне в обеих темах на синтетическом примере; сохранение patch через файловый провайдер телефона и живой гостевой запуск за лимиты отдельно не проверялись.
