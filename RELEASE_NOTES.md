# RemoteVibecode 0.3.9

- Все компоненты собираются из исходников в GitHub Actions. APK подписывается прежним ключом; CI проверяет его сертификат перед публикацией.
- Добавлена лицензия MIT; уведомления о лицензиях входят в комплект.
- Обновлены инструкции установки, обновления и диагностики; добавлены формы сообщений об ошибках и предложений.
- Интерфейс и привязка телефона сохраняются. Эта сборка обновляет упаковку и выпуск, а не меняет схему подключения.

## Обновление

APK устанавливается поверх существующего приложения. Для обновления агента сначала выберите «Выйти» в его трее, установите пакет или замените EXE и запустите агент снова. Версия ретранслятора 0.1.1 добавляет лицензионный файл и обновлённую документацию; протокол не изменён.

## Проверено и ограничения

Сборки Android, Arch, Windows и DEB выполняются в CI. Это не проверка полного маршрута на физическом Windows-ПК и не проверка установки DEB на каждой целевой ОС. Статус приложения остаётся предварительным.
