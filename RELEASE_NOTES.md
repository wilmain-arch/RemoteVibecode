# RemoteVibecode 1.0.0

Работа с Codex Desktop с телефона через собственный сервер.

- Чаты, проекты, планы, модели и усилие, субагенты, файлы и изображения.
- Светлая, тёмная и системная темы в едином дизайне «Фокус».
- Агент для Windows и Arch Linux, ретранслятор для Debian и Ubuntu.
- Исправлены повторная отправка при потерянном ответе, зависание очереди и гонка привязки.
- Улучшены обновление истории, файловые ссылки и восстановление фонового наблюдения.
- Повреждённая загрузка не перезаписывает существующий файл до проверки контрольной суммы.
- Добавлены ограничения соединений и закрытие зависших каналов.

## Обновление

Обновите APK, агент и ретранслятор. Привязка и данные сохраняются. Перед перезапуском агента или ретранслятора дождитесь завершения задач и очереди.

[Установка](https://github.com/wilmain-arch/RemoteVibecode#readme) · [Порядок обновления](https://github.com/wilmain-arch/RemoteVibecode/blob/main/docs/UPDATING.md)

## Ограничения

Атомарная корректировка нативной очереди Desktop и общий поиск по всем чатам недоступны. При неизвестном исходе запуска повтор блокируется, чтобы не выполнить задачу дважды. Android может ограничивать фоновые уведомления после принудительной остановки приложения. Ошибка файлового провайдера при финальной записи не гарантирует атомарность замены файла.
