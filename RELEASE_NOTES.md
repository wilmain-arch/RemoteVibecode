# RemoteVibecode — предварительная версия

Загрузите три файла: APK на Android, EXE на ПК с Windows, DEB на собственный сервер Debian 13 или Ubuntu 26.04.

Порядок установки и настройки: [README](https://github.com/wilmain-arch/RemoteVibecode#readme). Контрольные суммы файлов — в `SHA256SUMS.txt`.

APK подписан отладочным ключом. Полный маршрут телефон → сервер → ПК пока не проверен на реальной установке.
