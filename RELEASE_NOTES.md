# RemoteVibecode

- В итог задачи добавлены наблюдаемые токены и изменение лимитов за 5 часов и неделю. Замер лимитов общий для аккаунта; параллельные чаты могут влиять на него.
- Сброс лимитов через доступные кредиты аккаунта с подтверждением. Повтор после обрыва связи использует тот же идентификатор запроса.
- В ленте отображаются начало работы, смена модели сервером и причина ошибки задачи.
- Для старых задач без замеров показывается отсутствие данных.
