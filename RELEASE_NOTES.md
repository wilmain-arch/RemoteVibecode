# Файлы по ссылкам в чате

- Можно открыть и скачать файл вне проекта, если он указан в ссылке текущего чата.
- Для внешнего файла показывается отдельная папка «Файл из чата». Соседние файлы не становятся доступны.
- Исправлены ссылки с пробелами в `<…>` и номерами строк.

Обновите агент ПК и Android-приложение. После обновления агента обновите чат. Ретранслятор менять не требуется.

Файл должен существовать на ПК и быть доступен агенту. Символические ссылки не поддерживаются; предел скачивания — 40 МБ.
