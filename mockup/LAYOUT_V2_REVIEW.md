# Альтернативная компоновка 0.9

Интерактивный вариант: `layout-v2.html`. Исходный цельный макет 0.8.1 оставлен в `hybrid.html` для сравнения. Оба используют одни цвета и типографику: меняется расположение элементов.

| Область | Компоновка 0.8.1 | Вариант 0.9 |
| --- | --- | --- |
| Чат | Отдельные шапка и строка проекта; модель над композером | Один заголовок с проектом и состоянием; модель внутри строки действий композера |
| Файлы | Название экрана, контекст и вкладки вверху | Имя проекта — заголовок; поиск сразу под ним; «Проект / Передача» закреплены внизу |
| Просмотр | Имя, путь и действия занимают верх документа | Имя и путь в одной шапке; документ начинается сразу, действия закреплены внизу |
| Проекты | Текущий проект отдельной строкой перед чатами | Имя текущего проекта в шапке и группе чатов, без повторной строки |

Вариант 0.9 даёт документу и списку файлов больше места по вертикали. Действия с файлом доступны большим пальцем, даже если пользователь прокрутил документ. Навигацию «Проект / Передача» легче найти внизу, но закреплённый переключатель забирает около 60dp высоты списка. На экране 360px две кнопки предпросмотра остаются в одну строку.

Для нативной реализации нужно проверить системные поля, клавиатуру, увеличенный шрифт, TalkBack и жест назад. Строка модели в композере должна иметь область касания не менее 48dp и уметь сокращаться на 360dp. Примеры имён и размеров в макете служат образцом, не живыми данными. Android-приложение пока использует компоновку 0.7.0.
