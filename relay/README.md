# Ретранслятор RemoteVibecode для Debian 13 и Ubuntu 26.04

Ретранслятор устанавливается на ваш сервер и соединяет телефон с агентом на ПК. Пакет не устанавливает Codex, агент или Android-приложение. Один экземпляр обслуживает один агент ПК и несколько одновременных соединений телефона.

## Установка

Скачайте `remotevibecode-relay_0.1.0_all.deb` из [общего релиза](https://github.com/wilmain-arch/RemoteVibecode/releases/latest) и установите на сервере:

```sh
sudo apt install ./remotevibecode-relay_0.1.0_all.deb
sudo systemctl status remotevibecode-relay
```

Откройте входящие **TCP-порты 8765, 8766 и 8767** в межсетевом экране сервера и панели хостинга. Порт 8765 принимает соединения телефонов; 8766 и 8767 используются агентом ПК. Для смены портов измените `/etc/default/remotevibecode-relay` и перезапустите службу. Публичный IP-адрес или доменное имя должны вести на сервер.

При первой установке пакет создаёт секрет и TLS-сертификат в `/etc/remotevibecode/`. Передайте агенту на ПК адрес сервера, секрет и отпечаток сертификата:

```sh
sudo cat /etc/remotevibecode/relay-secret
openssl x509 -in /etc/remotevibecode/relay-cert -noout -fingerprint -sha256
```

**Не помещайте секрет в ссылку, QR-код, снимок экрана или журнал поддержки.** При обновлении пакета секрет и сертификат сохраняются; при полном удалении пакета удаляются.

## Управление

```sh
sudo systemctl status remotevibecode-relay
sudo journalctl -u remotevibecode-relay -f
sudo systemctl restart remotevibecode-relay
```

Ретранслятор передаёт данные телефона мосту без расшифровки; телефон проверяет TLS-сертификат моста по отпечатку из QR-кода. Отдельный сертификат сервера защищает соединения агента. Домашнему роутеру ПК проброс портов не нужен: агент сам подключается к серверу.

Полный маршрут на реальном Windows-ПК и публичном сервере пока не проверен.
