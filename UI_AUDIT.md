# Аудит интерфейса Android-клиента — 30.09.2026

Осмотр выполнен на OnePlus 9 Pro через ADB в тёмной теме: основной чат, открытая клавиатура, список проектов, выбор модели и список файлов. Проверена фактическая структура событий `thread/read` локального app-server.

## Исправлено в этом проходе

| Приоритет | Наблюдение | Изменение |
| --- | --- | --- |
| Высокий | «Ход работы» показывал только общее описание; команды, чтение файлов и просмотр изображений не были видны | Мост передаёт безопасные краткие подписи событий; приложение показывает их внутри раскрываемого блока |
| Высокий | Касание модели сразу меняло настройку, в том числе при случайном нажатии | В выборе модели и усилия появились черновик, «Отмена» и «Применить»; есть возврат к настройкам чата |
| Высокий | Список проектов разворачивал все чаты сразу, что затрудняло навигацию | Проекты сворачиваются; исходно раскрыт только проект выбранного чата, поиск раскрывает совпадения |
| Средний | Поле ввода имело два вложенных контура и занимало много места с клавиатурой | Поле заменено компактным текстовым вводом внутри общей панели |
| Средний | При смене чата сохранялась позиция прокрутки предыдущей истории | Состояние списка привязано к ID чата |
| Средний | Эффективная модель чата ошибочно превращалась в явное переопределение при отправке | Модель и усилие передаются только после явного выбора пользователем |

## Доработка по оставшимся пунктам — версия 0.6.0

| Пункт | Результат |
| --- | --- |
| Оформление сообщений | Добавлены заголовки, акценты, списки, цитаты, блоки кода, таблицы и ссылки. Внешние HTTP(S) ссылки открываются на телефоне; ссылки на локальные файлы ПК копируют путь. |
| Длинная история | Мост отдаёт страницы по 60 элементов с устойчивым курсором; кнопка «Показать ранние сообщения» загружает предыдущую страницу. В каждом ходе остаются последние 30 действий. |

| Задержка статуса | Добавлен длинный запрос событий app-server с немедленным обновлением чата при изменении; периодический опрос сохранён как резерв. |
| TalkBack | Выбранные чат, модель и усилие объявляются как выбранные; действия получают текстовые подписи. |

## Оставшиеся границы

- Оформитель поддерживает основные элементы Markdown; вложенные конструкции и HTML не обрабатываются. JPEG, PNG, WebP, GIF и BMP показываются в истории и файлах; увеличение изображения по касанию пока отсутствует.
- Полный вывод команд и внутренний текст рассуждений не передаются на телефон. Пометки содержат краткие безопасные подписи.
- Прогресс передачи виден, пока приложение открыто; отдельной фоновой службы для скачивания нет.

Внутренний текст рассуждений не отображается: используются опубликованные сводки и метаданные действий из app-server.
