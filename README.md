# RemoteVibecode

Отдельная APK для подключения через собственный ретранслятор описана в
[android/RELAY_APK.md](android/RELAY_APK.md). Она устанавливается рядом с
личной версией приложения.

Версия 0.9.6: текст сообщений можно выделить и скопировать; изображения в чате открываются на весь экран и сохраняются через системный выбор файла. Ссылки Markdown на файлы внутри проекта открывают содержащую их папку. Сообщения в очереди видны над полем ввода и в истории; принятые мостом можно отправить как корректировку активного хода. Для этих возможностей нужен обновлённый локальный мост на ПК; схема подключения телефона не меняется.

Личный Android-клиент для работы с задачами Codex своего ПК без RDP. Версия 0.9.6 показывает проекты и чаты, форматирует Markdown, загружает ранние сообщения страницами, выводит время, вложения, изображения и пометки действий. Чат обновляется по событиям моста. Проекты можно сворачивать, а модель и усилие менять с подтверждением. Остаток лимита за 5 часов и неделю, время сброса и обновления показаны на экране «Проекты». Светлая, тёмная и системная темы выбираются на экране «Проекты»; выбор сохраняется после перезапуска. Приложение поддерживает русскую клавиатуру и передачу файлов в обе стороны. Экран «Файлы» показывает папки проекта выбранного чата, предпросмотр с действиями и вкладку передачи; описание сценариев — в `FILE_WORKFLOW.md`. Текущая иконка RemoteVibecode находится в ресурсах Android; для системной темы есть монохромный вариант. Интерфейс использует векторные иконки Lucide (лицензия ISC: `third_party/lucide/LICENSE`).

После однократной привязки приложение открывает последний выбранный чат без формы входа. Привязка даёт приложению доступ к Codex на ПК, поэтому её код и токен нельзя публиковать. Токен зашифрован Android Keystore. Для отключения телефона есть действие в боковом меню, для отзыва утерянного телефона — `./reset-pairing.sh` на ПК.

## Установка

1. Убедиться, что на ПК работает `codex-phone-companion.service`. Дома телефон использует локальную сеть; извне — Tailscale на телефоне и маршрутизатор подсети домашнего сервера.
2. Собрать APK или запустить `python3 serve-apk.py` в папке проекта. Временная страница установки доступна 30 минут по LAN-адресу ПК, в том числе через маршрутизатор подсети.
3. Установить APK, открыть ссылку привязки со страницы. Запасной путь — `./show-pairing-qr.sh` на ПК и сканирование QR в приложении.
4. Впоследствии открыть приложение: чат появится сразу. Если код истёк, перезапустить службу моста и открыть новую страницу.

```bash
systemctl --user status codex-phone-companion.service
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ANDROID_HOME="$HOME/Android/Sdk" ./android/gradlew -p android assembleDebug
python3 serve-apk.py
```

После сборки APK находится в `android/app/build/outputs/apk/debug/app-debug.apk`. С телефона файл выбирается системным picker и отправляется в `inbox/`; файл для телефона помещается в `outbox/` и сохраняется на вкладке «Передача» экрана «Файлы». Лимит — 40 МиБ на файл, целостность проверяется SHA-256. Локальная очередь сообщений и черновики переживают перезапуск приложения; сообщения в очереди и текущую передачу можно отменить. Мост запускает Codex app-server по запросу и закрывает после 15 секунд простоя.

## Устройства ADB

Инструкция в приложении: откройте **☰ Проекты → Устройства ADB → Добавить устройство**. Мастер показывает три шага: подготовка телефона, выбор сетевого пути и ввод адреса с основным портом отладки. После сохранения профиля откроется экран с сопряжением и подключением. Можно сохранить несколько телефонов; каждый имеет свой адрес, порт и состояние.

1. На добавляемом телефоне включите **Настройки → Для разработчиков → Беспроводная отладка** и разрешите текущую сеть Wi‑Fi. С основного экрана отладки возьмите **IP-адрес и порт**. Для доступа извне адрес должен быть достижим через выбранную частную сеть.
2. В мастере выберите **«Через домашний сервер»**, если телефон доступен серверу по частной сети, либо **«Напрямую с ПК»**, если ПК сам видит его IP-адрес. Введите название, IP-адрес и основной порт.
3. Если этот ПК ещё не находится в списке сопряжённых устройств, на телефоне откройте **«Подключить устройство с помощью кода сопряжения»**. Пока окно открыто, перенесите **порт сопряжения и шестизначный код** в приложение и нажмите «Сопрячь с ПК». Порт сопряжения отличается от основного.
4. Нажмите **«Подключить и проверить»**. При успехе статус станет «Подключено», а устройство появится в `adb devices` на ПК. Для уже сопряжённого телефона шаг 3 не нужен.

Если Android сменит основной порт после переключения сети или отладки, откройте профиль устройства, обновите порт и подключитесь снова. Экран показывает последнюю связь, ошибку и историю переходов соединения; мост повторяет подключение по сохранённому порту каждые 30 секунд. Сопряжение и включение отладки всегда подтверждаются на самом телефоне. Если нужен SSH-ретранслятор для ADB, задайте адрес собственного сервера через `CODEX_ADB_RELAY` в локальной службе и перезапустите её. Мосту требуется доступ к SSH-серверу по ключу без ввода пароля.

ADB здесь работает **на ПК**, а приложение управляет только добавлением, сопряжением и проверкой устройств. Транспорт вынесен в профиль: прямой TCP или SSH-ретранслятор. За пределами одной сети телефону нужен достижимый частный маршрут; наличие Tailscale на ПК не обязательно.

## Публичная версия

Репозиторий содержит исходники Android-приложения, личного моста, серверного ретранслятора и предварительной версии [Windows-агента](agent/README.md). `relay/` собирается в пакет `.deb` для сервера Debian 13 или Ubuntu 26.04; агент собирается в `.exe` через GitHub Actions. Эти компоненты пока не проверены вместе на реальном Windows-ПК. Пример пользовательской службы моста — `codex-phone-companion.service.example`; личные адреса и ключи не входят в репозиторий.
