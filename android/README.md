# Android-приложение RemoteVibecode

Скачайте `RemoteVibecode-0.9.16.apk` из [последнего релиза](https://github.com/wilmain-arch/RemoteVibecode/releases/latest). Приложение подключается через ваш ретранслятор. Идентификатор `ru.wilmain.codexphone.relay` сохранён, поэтому новая APK обновляет прежнюю relay-сборку без потери привязки.

1. Установите серверный пакет `remotevibecode-relay` на собственном сервере и
   откройте TCP-порты 8765, 8766 и 8767 (либо порты из его конфигурации).
2. Настройте агент на ПК с адресом сервера, секретом ретранслятора и
   отпечатком сертификата ретранслятора. Codex Desktop или CLI должен быть
   установлен и авторизован на этом ПК.
3. Запустите агент и откройте его QR-код привязки.
4. В приложении **RemoteVibecode** нажмите «Сканировать QR-код» и
   считайте код агента. Код привязки, адрес ретранслятора и отпечаток сертификата
   *моста* передаются в QR. Секрет ретранслятора на телефон не передаётся.

Приложение закрепляет TLS-сертификат моста и обращается только к адресу из
QR-кода. Авторизацию запросов обеспечивает токен, выданный мостом после
проверки кода привязки. Трафик проходит по маршруту телефон → ретранслятор → агент →
мост, без входящего порта на домашнем роутере ПК.

APK подписан отладочным ключом проекта. При обновлении сохраните прежнюю
установку приложения; удаление стирает локальный токен привязки.

Сборка исходников: `./gradlew :app:assembleRelayDebug --offline` в каталоге
`android/`. Артефакт появится в
`app/build/outputs/apk/relay/debug/app-relay-debug.apk`. В релизе файл называется
`RemoteVibecode-0.9.16.apk`.

## Расход задачи и сброс лимитов

После завершения задачи лента показывает наблюдаемые токены и изменение лимитов за 5 часов и неделю. Лимиты общие для аккаунта, поэтому замер может включать параллельную работу в других чатах. Старые задачи без замеров восстановить нельзя.

На экране проектов под лимитами находится кнопка сброса. Она использует доступный кредит аккаунта после подтверждения. При потере связи нажмите «Проверить результат сброса»: повторяется тот же запрос. Без кредитов произвольный сброс недоступен.
