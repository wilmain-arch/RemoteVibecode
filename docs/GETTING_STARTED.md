# Первый запуск

[← Главная](../README.md)

## Что понадобится

- Телефон с Android 8.0 или новее; камера нужна для QR-привязки.
- ПК с Codex Desktop и выполненным входом в ваш аккаунт. На Arch путь обычно определяется автоматически. Codex CLI — резервный вариант, не гарантия одинакового набора моделей.
- Windows x64 или Arch Linux для готового агента. Поддержка всех версий Windows не подтверждена; проверенный EXE собирается на Windows runner GitHub, работа на физическом ПК ещё требует проверки.
- Собственный сервер с Debian 13 или Ubuntu 26.04, Python 3.10+, OpenSSL и systemd. Зависимости устанавливает пакет.
- Связь телефона и ПК с сервером. Для публичного интернета — доступный домен/IPv4 и TCP 8765, 8766, 8767.

## 1. Сервер

Следуйте [серверной инструкции](../relay/README.md). После установки `systemctl status remotevibecode-relay` должен показывать `active (running)`. Получите секрет и SHA-256 сертификата и сохраните их для настройки агента.

На VPS проверьте межсетевой экран ОС и правила панели хостинга. Для домашнего сервера доступ из интернета требует настройки маршрута/проброса портов на его роутере; при CGNAT одного проброса недостаточно. Можно использовать собственную VPN-сеть. На роутере клиентского ПК проброс не нужен.

## 2. ПК

[Windows](../agent/README.md) · [Arch Linux](../arch/README.md)

Запустите Codex Desktop и войдите в аккаунт, затем агент. Введите адрес сервера, секрет и отпечаток его сертификата. Дождитесь доступного соединения и откройте QR-код.

## 3. Телефон

Скачайте APK из [последнего релиза](https://github.com/wilmain-arch/RemoteVibecode/releases/latest). Разрешите установку из используемого браузера или файлового менеджера, установите приложение и выберите «Сканировать QR-код». Разрешите камеру. Код действителен 30 минут.

После привязки должен появиться список проектов и чатов. Выберите чат и отправьте короткое сообщение. Если список или ответ не появились, откройте [диагностику](TROUBLESHOOTING.md).

## Что сохраняется

Аккаунт Codex остаётся на ПК. Телефон хранит токен привязки, выбранный чат и черновики. Секрет сервера вводится в агент и не передаётся в QR. Не публикуйте QR, секрет или файлы конфигурации.
