## Реализовано

| Сценарий | Результат | Ограничение |
|---|---|---|
| Файлы | Страницы по 200, поиск по именам всей открытой папки, скрытые/служебные переключатели | Поиск не рекурсивный. Более 50 000 элементов дают явную ошибку. |
| Символические ссылки | Внутренние доступны; внешние/недоступные показаны с объяснением и без открытия | Цель внешней ссылки не раскрывается. |
| Курсоры | Привязаны к снимку списка и фильтрам, изменения требуют обновления | Изменение каталога между страницами прерывает старую пагинацию. |
| Совместимость | Авторизованный /api/capabilities, версия протокола и агента, флаги функций; старый агент получает пояснение | Версия Desktop отдельно не выдаётся. Полная матрица всех версий Desktop не проверена. |
| Очередь | Сверка нативных записей с очередью и историей, синхронизация текста, подтверждение доставки | Исчезновение без receipt остаётся «Проверяем состояние», не считается отменой. |
| Повторы | Принятые мостом сообщения не отправляются автоматически повторно | Поддержка нативной атомарной корректировки не доказана; действие явно недоступно. |

## Проверки

- 68 Python-тестов: временные каталоги, три страницы/421 файл, поиск за первой страницей, изменение снимка/фильтров, повреждённые курсоры, внутренние/внешние ссылки, очередь с имитацией Desktop, HTTP/control/plan регрессии.
- 14 различных UI-сценариев на телефоне в отдельном taskfixture-пакете. В первой серии два сценария потеряли тестовую Activity; оба прошли при повторном запуске. Тест пагинации сначала неверно искал ещё не созданную LazyColumn кнопку; исправлен на прокрутку к узлу и прошёл повторно.
- Проверены новый экран совместимости без вызова действий, поиск/видимость/пагинация файлов, прежний локальный поиск, корректировка очереди, сценарии инструментов чата (планы, поиск, подтверждения, восстановление формы).
- Синтетический скриншот файлов просмотрен. Генерированные макеты не использовались вместо работающего интерфейса.
- Основная и тестовая APK собраны; py_compile и git diff --check прошли.
- Тестовые пакеты удалены, основное приложение запущено. Глобальные настройки телефона не изменялись.

## Ожидают проверки / ограничения

Новые API через фактический маршрут телефона после безопасной активации агента; живые изменения/удаление очереди в Desktop; потеря процесса/перезагрузка телефона и гарантии фоновых уведомлений; Windows GUI и живое подключение на Windows; все сочетания тем, увеличенного шрифта и ориентации для новых элементов. Модельные задачи и платные review не запускались. Проверки очереди с имитацией не являются подтверждением семантики всех версий Desktop.

Исходники опубликованы в ветке main. GitHub Release и тег не создавались. Личные скриншоты и данные не публиковались.
