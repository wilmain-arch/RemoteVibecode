# Если что-то не работает

[← Главная](../README.md)

| Симптом | Что проверить |
| --- | --- |
| Агент не подключается к серверу | Адрес без лишних символов, доступность TCP 8766 и 8767, секрет, отпечаток сертификата. На сервере служба должна быть active. |
| Телефон не подключается | Доступность сервера с телефона и TCP 8765. Если адрес локальный, мобильный интернет сам по себе не даёт к нему доступа. Нужна общая сеть или настроенный маршрут. |
| QR не принимается | Создайте новый код в агенте: старый истекает через 30 минут или после привязки. Камере разрешён доступ? |
| Ошибка сертификата | Сверьте SHA-256 с текущим сертификатом сервера. После замены сертификата нужно обновить настройки. Не отключайте проверку для обхода ошибки. |
| Codex не найден / нет чатов | Запустите Desktop и войдите в аккаунт. Проверьте путь в настройках агента: нужен встроенный исполняемый файл codex, а не оболочка запуска Desktop. На Arch обычно `/usr/lib/chatgpt/resources/codex`. |
| Модель не поддерживается | Выберите модель из списка приложения. Убедитесь, что используется нужный Desktop и его аккаунт; CLI может предоставлять другой набор моделей. |
| Чат открыт в другом приложении | Завершите работу с этим чатом в другом клиенте и повторите. Не запускайте одну задачу одновременно в разных клиентах. |
| Связь кратковременно пропала | Проверьте сеть и статус агента. Сообщение может уже находиться в очереди: проверьте очередь перед повторной отправкой, чтобы не создать дубликат. |
| После обновления нет новых функций | Выйдите из агента через трей и запустите заново. Установка пакета не перезапускает старый процесс. |
| Нет расхода / 0% | Старая задача могла не иметь замера. Целые проценты скрывают небольшой расход. Лимиты общие для аккаунта. Подробнее — в раскрытом итоге задачи. |
| Сброс лимитов недоступен | Нужен доступный кредит аккаунта. При неподтверждённом сбросе используйте «Проверить результат сброса»: повторяется тот же запрос. |

## Журналы

- Windows: `%LOCALAPPDATA%\RemoteVibecode\agent.log`.
- Linux: `~/.config/RemoteVibecode/agent.log` (либо каталог `$XDG_CONFIG_HOME/RemoteVibecode`).
- Сервер: `sudo journalctl -u remotevibecode-relay -n 100 --no-pager`.
- Состояние сервера: `sudo systemctl status remotevibecode-relay`.

## Сообщить об ошибке

Откройте [форму ошибки](https://github.com/wilmain-arch/RemoteVibecode/issues/new/choose). Укажите версии APK, агента, Codex и ОС, шаги воспроизведения, ожидаемый результат и фактическую ошибку. Прикладывайте только относящийся к проблеме фрагмент журнала.

Удалите секреты, токены, QR-привязки, личные пути и содержимое переписки из материалов перед публикацией. Полный `agent.json` или `state.json` не нужен.

## Неопределённый исход отправки

После обрыва связи приложение проверяет прежний ID и не запускает задачу повторно автоматически. Если запись исчезла из очереди Desktop, действие «Скрыть уведомление» убирает локальное уведомление после подтверждения. Это не означает отмену или остановку задачи на ПК. Проверьте историю Desktop перед отправкой новой задачи.

## Фоновые уведомления

Наблюдаемые задачи сохраняются и восстанавливаются при следующем открытии приложения и при разрешённом Android перезапуске сервиса. Принудительная остановка, перезагрузка или ограничения батареи производителя могут отложить уведомление до открытия приложения. Разрешите уведомления; системные запреты приложение не обходит.
