# Файлы по ссылкам в чате

Ссылки на файлы внутри проекта открывают папку проекта.

Ссылка на файл вне проекта открывает отдельную папку «Файл из чата» с этим файлом. Можно посмотреть текст или изображение и сохранить файл на телефон. Для скачивания действует общий предел 40 МБ.

Доступ выдаётся только к отдельному существующему файлу, явно указанному в Markdown-ссылке текущего чата. Соседние файлы и внешние папки не открываются. Внутри проекта разрешены символические ссылки, которые остаются внутри его корня. Внешние ссылки и индивидуально разрешённые файлы не расширяют доступ на соседние файлы или папки. Индивидуальный файл доступен даже при отсутствующей рабочей папке чата.

После перезапуска агента обновите чат: мост снова прочитает ссылки из его истории. Если файл удалён, перемещён или недоступен пользователю агента, открыть его не получится.

Скачивание проверяется во временном файле до открытия назначения. Ошибка сети или контрольной суммы до сохранения не перезаписывает выбранный существующий файл. Ошибка записи самого провайдера Android может оставить неполную копию: универсальная атомарная замена для всех SAF-провайдеров не гарантируется.
