# Обновление

[← Главная](../README.md)

Версия комплекта (`bundle-v…`) объединяет независимо версионируемые APK, агент и ретранслятор. Состав всегда смотрите в описании релиза. Обновляйте указанные там компоненты; сервер не требуется переустанавливать при каждом изменении интерфейса телефона.

## Перед обновлением

Дождитесь завершения задач и отправки очереди сообщений. Скачайте файлы одного комплекта из [Releases](https://github.com/wilmain-arch/RemoteVibecode/releases/latest). Для проверки файлов используйте `SHA256SUMS.txt`: Linux — `sha256sum -c SHA256SUMS.txt`, Windows — `Get-FileHash .\RemoteVibecodeAgent.exe -Algorithm SHA256` и сравнение с файлом сумм. Проверяйте только скачанные файлы; отсутствие остальных вызовет сообщение об ошибке проверки.

## ПК

- **Windows:** выберите «Выйти» в меню значка агента в трее. Закрытие окна лишь скрывает его. Замените EXE и запустите новую версию.
- **Arch:** выйдите из агента через трей, выполните `sudo pacman -U ./remotevibecode-agent-ВЕРСИЯ-1-any.pkg.tar.zst`, затем запустите `remotevibecode-agent`.

Установка пакета сама по себе не обновляет уже запущенный процесс. Настройки сохраняются в каталоге RemoteVibecode профиля пользователя.

## Сервер

Если релиз меняет ретранслятор, выполните `sudo apt install ./remotevibecode-relay_ВЕРСИЯ_all.deb` и `sudo systemctl restart remotevibecode-relay`. Убедитесь, что служба активна. Секрет и сертификат сохраняются при обновлении. Не выполняйте purge для обычного обновления.

## Телефон

Установите APK поверх существующего приложения. Не удаляйте приложение и не очищайте его данные: это удалит локальную привязку и черновики. При ошибке несовместимой подписи не удаляйте приложение сразу — сохраните нужные данные и сообщите об ошибке.

Текущие APK подписываются ключом разработки. Для совместимых обновлений необходим тот же ключ подписи; переход на другой ключ требует отдельно объявленной миграции.

## После обновления

Проверьте список чатов, отправку сообщения и получение ответа. При обновлении Codex Desktop перезапустите агент после завершения задач. Если появилась ошибка модели, заново выберите модель из актуального списка.
