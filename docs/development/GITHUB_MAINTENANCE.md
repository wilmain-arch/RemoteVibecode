# Оформление GitHub — 01.10.2026

Внесены MIT, пользовательские инструкции, формы Issues/PR, изображение интерфейса агента, таблица состава комплекта и единый манифест версий. Старые бинарные файлы удалены из текущего дерева; опубликованные Releases и история Git сохранены.

Сборка комплекта переведена на исходники APK/Arch/Windows/DEB. Для Android публикация требует существующий ключ подписи из GitHub Secrets и сверяет публичный отпечаток с release.json. Обычный CI без Secrets выпускает лишь проверочный APK, не пользовательское обновление.

Локально проверяются сборка Android, создание DEB, синтаксис shell/YAML, согласованность версий и ссылки актуальной документации. Фактическое успешное выполнение нового CI указывается отдельно после запуска.

Ограничения проекта указаны в README: Windows-маршрут и установка пакета на каждой серверной ОС не выдаются за проверенные. Поддержка всех систем не подразумевается успешной компиляцией.
