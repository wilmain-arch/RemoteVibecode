# Гостевой и основной чат — общий интерфейс

Дата: 2026-10-05.

## Реализация

Гостевой чат использует CompanionUi вместо отдельной верстки. Гостевой адаптер преобразует журнал задач в ChatLine/LocalMessage и использует отдельные гостевые API. Токен владельца гостю не передается. GuestMode скрывает неподдерживаемые действия; серверные ACL сохранены.

Тематический Surface добавлен на корень управления гостями и всей гостевой сессии, включая переходы в общие ресурсы. Изменение темы из меню чата обновляет внешнюю тему сессии и индикаторы системных панелей. Изображения кешируются отдельно для профиля, рабочей области, чата и последней задачи.

## Функции

| Функция | Состояние |
|---|---|
| Основная лента, поле ввода, типографика | Общий CompanionUi |
| Прокрутка, клавиатура, переход вниз | Общая реализация; новый гостевой сценарий на устройстве еще не проверен |
| Проекты и чаты | Общий ProjectsScreen, только гостевые области; отдельные черновики |
| Светлая, темная, системная тема | Общие палитры, тематические поверхности; визуальная проверка новой сборки еще не выполнена |
| Модель и усилие | Общая панель, каталог доступных моделей |
| Копирование, выделение, Markdown, код | Общие компоненты |
| Файловые ссылки | Только внутри гостевой области, с проверкой пути мостом |
| Изображения | Markdown-ссылки на файлы гостевой папки, общий просмотр/увеличение, скачивание через SAF |
| Загрузка файла в чат | Системный выбор, до 4 МиБ; файл сохраняется под уникальным именем в гостевой области, ссылка добавляется в черновик |
| Очередь и отмена | Сообщение отображается один раз; стабильный operationId; отмена queued/active |
| Завершение и расход | Общая строка outcome, опубликованный счетчик measurement. Время выполнения гостевой задачи в API пока отсутствует |
| Общие ресурсы | Существующий просмотр и работа в копии, сохранение ACL |
| Обновления | Существующий экран приложения |
| Редактирование/корректировка очереди | Еще не реализовано в гостевом API |
| Полный журнал инструментов и планы | Еще не публикуется гостевым runner; UI показывает статус и опубликованные ответы |
| Субагенты, инструменты чата, Git/review, управление проектами | Еще не подключены к изолированному гостевому API; кнопки не выдаются за рабочие |
| ADB, выдача квот, управление гостями, сброс лимита владельца | Не предоставляются гостю |

Полное функциональное равенство с основным чатом еще НЕ достигнуто. Нельзя подключать guest adapter к owner API ради появления кнопок: это нарушит изоляцию и квоты.

## Проверки

- Основная APK собрана; lint прошел.
- Добавлены проверки темных/светлых поверхностей и одной записи очереди; тесты существующих черновиков/идемпотентности адаптированы к общему интерфейсу.
- Инструментальные тесты новой версии не выполнены: во время подготовки сборки устройство было недоступно. Предыдущие прогоны не считаются проверкой этих изменений.
- Основная APK 1.0.0 (versionCode 48) установлена через USB ADB с сохранением данных; приложение открыто. Визуальное сравнение, SAF, TalkBack и регрессия основного чата еще не проверены.
- Живые платные задачи не запускались, привязки и личные чаты не удалялись.
