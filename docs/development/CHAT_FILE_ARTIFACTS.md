# Изменения файлов в чате

Добавлен отдельный блок исторических изменений задачи из опубликованных событий `fileChange` Codex. Это не текущий Git diff.

- Имя файла, счётчики добавленных и удалённых строк, раскрываемый цветной diff.
- Переход к папке через существующий обработчик файловых ссылок.
- Сохранение одного изменения или всех изменений задачи в `.patch` через системный диалог Android.
- Содержимое экспорта фиксируется перед открытием системного диалога.
- Сокращённые и отсутствующие diff явно обозначаются; неполный patch не экспортируется.
- Гостевой runner публикует изменения во время выполнения и сохраняет их в итоговом результате; пути ограничены гостевой рабочей областью.
- Старые гостевые задачи без сохранённого `fileChange` не получают выдуманного diff.

Ограничения: до 100 изменений на ход, до 128 Ки символов на файл и 256 Ки символов на ход. Изменения, сделанные произвольной shell-командой без события `fileChange`, автоматически не реконструируются. Экспорт предназначен для сохранения опубликованного diff; применимость к текущей версии файлов не проверяется. Автоматическое применение отсутствует.

Основная APK успешно собрана и установлена через USB ADB с сохранением данных. Обновлённые модули локального моста установлены с резервной копией; работающий процесс не перезапускался во время активной задачи. Новая серверная проекция начнет работать после перезапуска агента.

Новые автоматические тесты, визуальная проверка diff и сохранение через SAF на телефоне на этом этапе не выполнялись. Платные модельные задачи не запускались. Коммит и публикация не выполнялись.

## Визуальная доработка

Блок соответствует C «Фокус»: свободный список без рамок и теней, единый набор векторных иконок, titleSmall для сводки, bodyMedium/Medium для имени файла, labelSmall для пути и статистики. Отступы 8/12 dp, строки минимум 56 dp; действия Material 3 с целями не менее 48 dp. Длинный путь сокращается в середине; имя файла переносится.

Diff — одна поверхность surfaceVariant с радиусом 12 dp, моноширинный текст 12sp/20sp, два столбца номеров строк из опубликованных unified hunks. Добавления используют secondary схемы «Фокус», удаления — error, фоны — соответствующий цвет с alpha 0.09. Обозначения +/− и доступные подписи дублируют цвет. Без опубликованного hunk номера не выдумываются.

Внутренняя прокрутка по вертикали ограничена высотой 288 dp; строки виртуализируются. Горизонтальная прокрутка сохраняет формат кода. Для строк длиннее 1024 символов есть предупреждение о частичном отображении; копирование и экспорт сохраняют исходный diff. Действия переносятся FlowRow при нехватке ширины. Общий экспорт — одна кнопка в заголовке, экспорт файла, копирование и переход доступны после раскрытия.

Применены android-native-dev/mobile-android-design (нативные компоненты, тематические цвета, цели касания), ui-design-system (типографика, сетка и токены), redesign-existing-projects (аудит визуальной иерархии и сокращение постоянных действий). Предложения веб-скилла о градиентах/текстурах не применялись: они противоречат утверждённому направлению.

Компонент просмотрен на USB-телефоне в отдельной временной Activity с синтетическими файлами в светлой и тёмной темах; проверено раскрытие и расположение действий, визуально подтверждены номера строк и цвета. Временная Activity удалена перед сборкой основной APK. Настройки телефона не менялись. SAF, TalkBack, шрифт 200%, очень большие diff и реальный маршрут моста в рамках этой доработки не проверялись.
