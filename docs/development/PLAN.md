# План развития Codex Phone Companion

Статус на 30.09.2026: версия 0.8.4 собрана; на телефоне пользователем проверена версия 0.8.3. Цель — удобный телефонный клиент к задачам Codex этого ПК без RDP. Приложение открывает последний чат после однократной привязки, работает через домашнюю сеть и Tailscale, передаёт файлы и принимает русский ввод. Текущая переработка добавила структуру чата ближе к ChatGPT, темы, проекты, список чатов, опубликованный ход работы, выбор модели и усилия.

## Завершено

1. Дизайн-контракт, макет и визуальная оценка светлой и тёмной тем: `DESIGN.md`, `design-contract.md`, `mockup/`, `MOCKUP_REVIEW.md`.
2. Мост с HTTPS, привязкой, очередью и файловым обменом. Codex app-server запускается по запросу и завершается после 15 секунд бездействия.
3. Каталог чатов, группировка по проектам, создание/выбор чата, каталог моделей и серверная проверка усилия. История содержит опубликованный ход работы.
4. Android-клиент на Kotlin/Compose с боковой панелью, поиском, листом моделей, черновиками по чатам, очередью и светлой/тёмной темами.
5. Сборка, установка и визуальная проверка на физическом телефоне, запросы к живому мосту.

## Следующие этапы

1. Инкрементальные события вместо полного опроса истории; отдельный кэш с восстановлением длинных чатов.
2. Проверить на телефоне отмену передачи и удаление ожидающих вложений версии 0.8.4; добавить фоновую передачу при закрытом приложении.
3. Вынести состояние и сеть из `MainActivity` в отдельные слои, заменить JSON-снимок моста на SQLite после схемы миграции.
4. Проверить доступность с TalkBack, масштабом шрифта и управлением без точных жестов; прогнать сценарии пропажи сети и отказа app-server.
5. Подготовить подписанную сборку и обновление без ADB.
6. Добавлять остальные возможности Desktop отдельными проверенными протоколами и экранами: review, разрешения, удалённые хосты, голос и рабочие деревья.

## Критерии следующего выпуска

Проверить созданный с телефона новый чат, отправку с явной моделью и усилием, доставку и ответ, файловый обмен с отменой, восстановление после обрыва сети, длинный чат и доступность обеих тем. Источник истины — Codex app-server; телефон хранит только привязку, выбор чата, черновики и очередь.
