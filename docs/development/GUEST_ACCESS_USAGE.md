# Гостевой доступ: локальная предварительная версия

## Владелец

1. Откройте список проектов → настройки → **Гостевой доступ**.
2. На Linux включите гостевой исполнитель. Мост проверит Codex Desktop, Bubblewrap и ограничения процессов. Для гостевого выполнения Desktop должен быть закрыт; общение владельца через APK остаётся доступным и имеет приоритет.
3. Нажмите **Пригласить гостя**, задайте имя и независимые правила для пятичасового и недельного окон.
4. Отправьте приглашение через **Поделиться приглашением** или покажите QR-код. Ссылка одноразовая, срок — 30 минут. Получателю нужна эта версия RemoteVibecode и сетевой доступ к адресу вашего ретранслятора.
5. Для совместной работы откройте **Проекты, чаты и изменения** у гостя. Предоставьте просмотр либо работу. Работа выполняется в отдельной копии; изменения оригинала применяются только после вашего подтверждения конкретного файла.
6. **Отозвать доступ** запрещает дальнейшие запросы, отменяет очередь и запрашивает остановку активной задачи. Уже скачанные гостем данные отозвать невозможно. Рабочие результаты на ПК сохраняются.

## Правила квот

Окна независимы. Можно оставить 5 часов без ограничения и выделить 15% недельного окна.

| Правило | Что происходит после сброса окна Codex |
|---|---|
| Без ограничения | Лимит гостя для этого окна отсутствует |
| Однократный бюджет | Израсходованная квота сохраняется |
| Пополнять после сброса | Выделение обновляется для нового окна |

База «от полной квоты» задаёт процентные пункты полного окна. «От остатка при выделении» выделяет долю оставшейся квоты. Настройка квот не стирает уже учтённый расход. **Выделить квоту заново** явно пополняет только выбранные окна. Во время измеряемой задачи или при несогласованном расходе сначала завершите задачу/согласуйте расход; пополнение в этот момент отклоняется, чтобы не потерять списание.

Счётчики провайдера округлены, поэтому остановка не гарантирует точного потолка до долей процента. Выполнение проверяется периодически. При смене окна или неоднозначном расходе задача блокирует дальнейшие гостевые запуски до ручного согласования владельцем; повторно автоматически не запускается.

## Гость

1. Откройте ссылку или отсканируйте QR в RemoteVibecode.
2. Нажмите **Открыть мой чат**. Основная привязка приложения остаётся прежней; гостевой профиль сохраняется отдельно.
3. Через **Чаты** создавайте отдельные переписки; черновики сохраняются для каждой. Через **Общие ресурсы** просматривайте предоставленное владельцем или создавайте рабочую копию.
4. **Файлы** открывает текущую гостевую рабочую папку. Поддерживаются загрузка до 4 МиБ, скачивание до 8 МиБ, текстовый просмотр и масштабирование изображений. Ссылки `/workspace/...` из ответа открываются в этой папке.
5. После потерянного ответа повтор использует прежний ID. Принятые задачи не запускаются повторно. Состояние с неизвестным исходом требует проверки владельцем.

## Ограничения этой версии

- Гостевой исполнитель реализован только для Linux. Обычная работа владельца на Windows сохраняется.
- Для гостевого запуска требуется закрыть Desktop. Внешнюю активность аккаунта на другом устройстве нельзя надёжно отнести к конкретному гостю.
- Общая папка предоставляется без `.git`, `.codex`, `.agents`, `.ssh`, `.aws`, служебных сборок, `.env*`, `auth.json`, `.pem` и `.key`. Это не универсальный поиск секретов; проверьте содержимое перед предоставлением доступа.
- Исполнитель ограничен памятью, CPU, процессами и размером отдельного файла. Объём гостевых данных контролируется мониторингом 256 МиБ / 10000 записей, без жёсткой файловой квоты; кратковременное превышение возможно.
- История предоставленного чата доступна для просмотра. Работа в копии не продолжает оригинальную историю и не изменяет файлы владельца автоматически.
- Живые платные задачи, все инструменты модели и длительная нагрузка на реальном аккаунте не проверялись. Проверки с синтетическим провайдером не заменяют проверку длительной работы реального аккаунта.

## Смена аккаунта владельца

При смене аккаунта Codex гостевые сессии отзываются, исполнитель отключается. Перезапустите агент, включите гостевой исполнитель и создайте новые приглашения. Жизненный цикл обновления токенов на реальном аккаунте ещё не проверен.
