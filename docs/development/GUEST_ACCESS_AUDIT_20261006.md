# Аудит гостевого доступа — 6 октября 2026

## Цель и границы

Проверить приглашения и сессии, независимые квоты 5ч/неделя, отзыв прав,
гостевые рабочие копии и файлы, очередь/отмену/восстановление, опубликованные
ответы и изменения файлов, интерфейс владельца и гостя, упаковку общего моста.
Используются временные базы, папки, имитация Codex и отдельная тестовая APK.
Личные задачи не запускаются и не удаляются; неоднозначные реальные задачи
не переотправляются. Секреты, сообщения и скриншоты пользователей не публикуются.

## План

1. Инвентаризация API, экранов, зависимостей и существующих тестов.
2. Регрессионные проверки подтверждённых дефектов до изменения кода.
3. Исправление ACL, файловых операций и ограничений хранилища.
4. Исправление идемпотентности, отмены и согласования расхода.
5. Исправление черновиков, очереди, ошибок загрузки и проверки изменений в APK.
6. Полный набор тестов моста; сборка и проверки синтетического UI через WiFi ADB.
7. Установка основной APK без удаления данных, итоговое ревью, commit и push.

## Карта зависимостей

- guest_access → SQLite: приглашения, хеши сессий, права, бюджеты, измерение.
- guest_jobs + guest_scheduler → очередь, единственная полоса измерения.
- guest_resources → права, рабочие копии, просмотр/загрузка, review владельцем.
- guest_runtime + guest_runner + guest_sandbox + guest_executor_gateway →
  частный исполнитель, приоритет владельца, изоляция Linux и опубликованные события.
- server → авторизация и HTTP API; controls → доступные возможности.
- GuestChatScreen → общие компоненты чата, сохранённый outbox и черновики.
- GuestAccessScreen / GuestSharingScreens / GuestWorkspaceScreen /
  GuestInvitationScreen / MainActivity → управление, файлы и вход.
- Общие модули моста входят в Windows и Arch агент; Android использует relay.

## Подтверждённые и исправленные дефекты

- Фильтр секретных каталогов при подготовке рабочей копии отличается от ACL чтения.
- Некоторые ответы чтения не проверяют отзыв прав после завершения операции.
- Review нового файла во вложенной папке не обрабатывает отсутствующий родитель.
- Предел общего хранилища не проверяется при окончательном сохранении копии.
- Результат согласования расхода теряет опубликованный вывод; повтор не идемпотентен.
- Отмена перед запуском может скрыть неопределённое измерение и заблокировать очередь.
- Повтор принятого приглашения после окончания его срока не восстанавливает ответ.
- Подтверждение отправки может очистить черновик другого выбранного чата.
- Локальное ожидающее сообщение имеет неверный ID чата и может исчезать из ленты.
- Пагинация допускает параллельные запросы, ошибка каталога моделей скрыта.

## Исходная проверка

50 гостевых Python тестов прошли до исправлений. Это не доказывает отсутствие
ошибок: перечисленные гонки и потерянные ответы требуют дополнительных тестов.

## Ограничения, которые нельзя выдавать за исправленные

Изолированный исполнитель доступен на Linux; закрытое окно Desktop — условие
существующей реализации. Проценты провайдера округлены; точный расход токенов
и строгая остановка до последнего процентного пункта не гарантируются.
Гостю не выдаются полномочия владельца на Git, ADB, независимые проекты,
создание субагентов и внутренние рассуждения. Отдельные оплачиваемые реальные
запуски не выполняются ради аудита.

| --- | --- | --- |
| Приглашение и сессия | Повтор потерянного ответа принятия доступен тому же устройству после истечения приглашения; отозванные сессии отклоняются | Новое устройство не принимает просроченный код |
| Независимые квоты | Запрет перераспределения во время активного/неопределённого измерения; повтор согласования идемпотентен и сохраняет ответы/артефакты | Расход измеряется округлёнными процентами провайдера |
| Очередь | Стабильный operationId, отмена до приёма записывается надёжно; принятый запрос можно сверить при выключенном исполнителе | Неопределённый запуск не повторяется автоматически |
| Выполнение | Проверка остановки до RPC; известный отказ запуска отделён от неопределённого результата; отзыв доступа прерывает выполнение | Linux, закрытое окно Desktop; живые оплачиваемые запуски не выполнялись |
| Причины ожидания | Различаются задачи владельца, его очередь, обновление, Desktop и неопределённый расход | Причина блокировки не раскрывает идентификаторы другого гостя |
| ACL и файлы | Повторная проверка прав после чтения; единый фильтр секретных каталогов; обход через симлинки запрещён | Владелец должен самостоятельно выбирать безопасные общие ресурсы |
| Хранилище | Финальная проверка бюджета, сериализация загрузок/копий; замена файла не учитывает его размер дважды | Контролируемый бюджет, а не жёсткая файловая квота |
| Проверка изменений | Отдельный полный список копий с пагинацией, включая копии без задач; просмотр diff; явное подтверждение выбранного файла; безопасная замена во вложенной папке | Удаления и двоичные изменения проверяются на ПК |
| Гостевой чат | Подтверждение относится к замороженному запросу; чужой/новый черновик сохраняется; сообщение очереди остаётся в нужном чате; модель/усилие сохраняются | Полномочия владельца гостю не выдаются |
| История общего чата | Корректная граница nextBefore, пагинация, отдельная навигация и пустое состояние | Общая история доступна только для чтения |
| Файлы и изображения | Отдельные ошибки списка/просмотра, повтор загрузки, обрезанный текстовый preview, уменьшение декодируемого изображения | Пределы передачи сохраняются |
| Формы и темы | Защита от двойных действий, неизменяемые поля во время запроса, прокрутка при крупном шрифте | TalkBack и все реальные устройства не проверены |

## Ограничения проверки и активации

Телефон оставался на защищённом экране блокировки: интерактивные проверки его
интерфейса не засчитываются. Проверки UI выполнены на эмуляторе; установка на телефон
подтверждена пакетным менеджером. Не проверены на реальном Codex оплачиваемое
выполнение, фактический расход квот и создание гостевых артефактов моделью.

Общие изменения моста используются агентами всех систем без новых зависимостей;
нативная упаковка Windows в этом аудите не собиралась. Возможность изолированного
гостевого выполнения на Windows не добавлялась.

Локальные модули моста установлены с резервной копией. Для активации нужен перезапуск
агента после завершения текущей задачи и очереди. Аудит не изменяет личные приглашения,
квоты, неопределённые задачи и настройки телефона. Новый релиз/тег этим изменением
не создаётся.
