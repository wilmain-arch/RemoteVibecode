# Файлы на телефоне: решение по интерфейсу

Основание: предоставленный снимок Codex Desktop с деревом проекта рядом с открытым `UI_AUDIT.md`, текущий Android-клиент 0.6.1 и API моста. Desktop показывает папки, поиск и чтение файла в контексте проекта. Раньше телефон показывал только `outbox` в нижнем листе, а загрузка с телефона была отдельной кнопкой композера.

## Реализовано в 0.7.0

В 0.8.4 передача допускает отмену, а удалённое до отправки вложение удаляется на ПК после восстановления связи. Повтор загрузки с тем же ID не создаёт второй файл.

В 0.8.0 эти действия перенесены в компоновку `mockup/layout-v2.html`: папки и файлы показаны без построчных разделителей, «Проект» и «Передача» закреплены внизу, поиск находится под заголовком текущей папки. В предпросмотре действия закреплены снизу, а широкая Markdown-таблица прокручивается горизонтально. Переключатель темы находится на экране проектов.

В верхней панели чата и в композере открывается один экран «Файлы» с двумя вкладками:

| Вкладка | Действия |
| --- | --- |
| Проект | Папки выбранного чата, поиск в открытой папке, предпросмотр текста и изображений, сохранение файла на телефон и подстановка пути в черновик сообщения через «Спросить Codex». Markdown показывается с оформлением. |
| Передача | Выбор файла на телефоне для следующего сообщения и скачивание из существующей папки `outbox` на ПК. |

Это разделяет работу с проектом и обмен файлами: при чтении файла пользователь остаётся в контексте выбранного чата, а отправка файла по-прежнему требует явного сообщения. Кнопка «Спросить Codex» заполняет черновик и не отправляет его автоматически.

## Границы и безопасность

- Корнем служит `cwd` выбранного чата из app-server. API не принимает произвольный корень с телефона. Выход через `..`, абсолютные пути, скрытые элементы и символьные ссылки отклоняются.
- Просмотр проекта только для чтения. На телефоне нельзя удалять, переименовывать или редактировать файлы ПК. Скачивание ограничено 40 МиБ, как и существующая передача; целостность проверяется SHA-256.
- Список ограничен первыми 200 элементами папки; поиск фильтрует показанные элементы этой папки. Текстовый предпросмотр ограничен 128 КиБ от сервера и 20 000 символами на экране. JPEG, PNG, WebP, GIF и BMP отображаются в списке, чате и на экране файла; максимальный размер изображения — 20 МиБ. Для остальных двоичных файлов доступно скачивание без предпросмотра.
- Сервер требует существующий bearer-токен; Android продолжает проверять TLS-сертификат ПК.

## Следующая итерация

1. Поиск по всему проекту на сервере с ограничением времени и результатов, а также фильтр по типу и признак изменённых файлов Git.
2. Предпросмотр PDF через отдельное ограниченное по размеру представление.
3. «Недавние файлы» и прямой переход из пометки `Прочитан файл` в браузер файлов.
4. Явный выбор папки назначения при загрузке с телефона, если потребуется переносить файлы на ПК без отправки их Codex.

Редактирование файлов ПК с телефона потребует отдельного дизайна: состояния изменений, разрешения конфликтов и подтверждения записи. Оно не включено в режим чтения.
