# RemoteVibecode: направления визуального развития

Статус: выбор направления. Код APK не изменять до выбора пользователя.

## 1. Visual Theme & Atmosphere
Android, обычный Material 3. Нейтральные плоские поверхности и свободный текст. A «Полотно» рекомендован: компактная шапка и нижняя строка модели внутри единого ввода. B «Рабочее пространство»: постоянная навигация Чат / Файлы / Агенты, контекст проекта сверху. C «Фокус»: более крупный заголовок и типографическая иерархия, малозаметные действия, более свободные интервалы. Все три — предложения, а не реализованная APK.

## 2. Color
Общие опорные пары для сравнения: Light фон #F8F9F7, поверхность #EBEEEA, текст #202321, вторичный #565D58, акцент #247661. Dark фон #141715, поверхность #242A25, текст #F2F4F1, вторичный #A0A8A2, акцент #90D4BB. Акцент используется для связи и выбранного состояния, не для украшения.

## 3. Typography
Системный Android sans-serif. Ответ 16sp/25sp; кнопки 14sp; метаданные 12sp/16sp. A заголовок 20sp/24, B 20sp/24, C 24sp/30. Сгенерированные изображения не являются точной проверкой размеров и шрифта.

## 4. Spacing & Grid
Экран 390×844 dp как условный ориентир. A боковые 20dp, B 16dp, C 24dp; сетка 4/8/12/16/24/32dp. Интерактивные цели минимум 48dp. Видимая иконка 20–24dp. Без внешней рамки телефона.

## 5. Layout & Composition
Сценарии: чат светлый / чат тёмный / проекты светлые / файлы светлые / изображение тёмное. Одинаковые тестовые данные во всех вариантах. Проекты перед самостоятельными чатами; сортировка данных не меняется. История занимает всё доступное пространство между шапкой и вводом. Навигация B должна скрываться при IME без потери альтернативного доступа; этот риск требует проверки после выбора.

## 6. Components
Flat AppBar, раскрываемая строка хода работы, пузырь только у пользователя, свободный ответ, один блок ввода радиусом 24dp. Иконки одной толщины. Ответ и действия копирования группируются по логическому сообщению. Проект — свободная строка 64dp с переносом; файлы — строки с типом/миниатюрой. Viewer показывает изображение Fit, закрытие, сохранение и сброс увеличения. В B NavigationBar имеет три назначения существующих экранов, без новых backend-функций.

## 7. Motion & Interaction
Обычные Material переходы 150–250ms. Очередь видна над вводом, корректировка доступна. Завершение — тихая строка времени/расхода. Все состояния связи подписаны текстом. Insets и IME учитываются один раз; чтение старых сообщений не прокручивает ленту принудительно вниз. Масштаб шрифта не отключать.

## 8. Voice & Brand
Название RemoteVibecode. Короткий русский текст, без технической воды и декоративной статистики. Тестовый чат «Обновление интерфейса», проект «Приложение», сообщение «Обнови интерфейс». Ответ «Обновил компоновку. Добавил светлую и тёмную темы.»; 3 действия; «Готово · 2 мин 14 с · 1% за 5ч». Файлы README.md, app.kt, preview.png. Изображение: мятный круг на тёмном фоне.

## 9. Anti-patterns
Не использовать Expressive, стекло, градиентные кнопки, шум/текстуру, рамки вокруг ответов, вложенные карточки, крошечный текст, дополнительные dashboard-метрики, декор в шапке, новые неподдерживаемые действия, перспективу и мокапы устройств. Изображения не выдавать за скриншоты APK. Личные данные не включать в генерацию и публикацию.
