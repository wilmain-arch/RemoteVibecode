# Реализация
WorkspaceControls.kt использует существующий HTTPS callback и общие токены. Все действия идут через whitelist Controls в bridge/controls.py; произвольного RPC/shell endpoint нет. MainActivity загружает вокруг найденного хода, сохраняет старую историю при обновлении и синхронизирует localQueue по clientId. Все платформы агента импортируют один bridge.server; пакет Arch обязан включить controls.py. Новый клиент сохраняет прежнюю привязку и транспорт. Дополнительные функции создания субагента недоступны без подтверждённого протокольного API.
