# Вторая очередь: дополнение к «Фокусу»

## 1. Visual Theme & Atmosphere
Сохраняется C «Фокус»: плоские поверхности, свободные списки, минимум постоянных действий. Основной чат не превращается в панель управления.
## 2. Color
Используются lightPalette/darkPalette приложения. Новые экраны не определяют отдельные цвета. Системная тема наследуется от главного MaterialTheme.
## 3. Typography
appTypography: заголовок экрана headlineSmall, раздел titleMedium, содержимое bodyLarge/bodyMedium, пояснения bodySmall. Увеличение шрифта не отключается.
## 4. Spacing & Grid
24dp края, 12dp между элементами, цели 48dp. Длинные действия и заголовки переносятся. Широкий набор разделов прокручивается по горизонтали.
## 5. Layout & Composition
Меню чата → Инструменты чата. Разделы: Чат, Поиск, Архив, План и цель, Очередь Desktop, Проекты, Git. Меню пользовательского сообщения открывает действия для его хода. Поиск ограничен текущим чатом и показывает его название и фрагмент; переход загружает участок истории вокруг хода.
## 6. Components
Общая UiScreenHeader; свободный LazyColumn; FilterChip без рамок; Material3 TextField поиска; прокручиваемый AlertDialog для ввода и подтверждения. Нагрузка, ошибка/повтор и пустое состояние явно различаются.
## 7. Motion & Interaction
Запрос поиска отменяется при смене строки/раздела; пагинация использует непрозрачный cursor. Диалоги сохраняют введённые поля при ошибке. Действия блокируются на время запроса. IME не закрывает содержимое; действие поиска/перехода убирает клавиатуру. Очередь отображается только в ленте, без второго блока над вводом.
## 8. Voice & Brand
Русские короткие подписи. Подтверждения объясняют влияние на историю, файлы, Git и лимиты. Названия состояний цели локализованы в интерфейсе.
## 9. Anti-patterns
Не создавать независимый чат под видом субагента. Не называть откат истории откатом файлов. Не удалять каталог при удалении проекта. Не скрывать запуск задач и расход лимитов. Не сохранять изображение теста с личной перепиской в Git.
