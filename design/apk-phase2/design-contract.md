# Контракт
Основание — текущие Compose-компоненты и утверждённый C «Фокус». Сохранены палитры, типографика, свободная лента, ввод, изображения и файлы. Добавлены вторичные инструменты в отдельном экране. Генеративные макеты не нужны: изменения описаны через существующие компоненты и схемы ниже.

Чат: шапка […] → Инструменты → раздел → свободный список → действие → подтверждение/форма → результат или ошибка с повтором.
Сообщение: копирование · […] → инструменты выбранного хода → ветка / откат.
Поиск: строка → фрагменты → открыть → участок реальной ленты.
Очередь: Desktop является источником своей очереди; локальная запись — транспортное ожидание до подтверждения; clientId связывает её с доставленной историей. При явных overrides модели/усилия/режима сохраняется очередь моста, поскольку native queue/add не передаёт эти параметры.

Проверка: синтетические данные, обе темы, шрифт 200%, отказ сети, подтверждения, отсутствие платных вызовов и публикации личных данных.
