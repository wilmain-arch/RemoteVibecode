# Проверка агента 0.4.0

## Реально выполнено

- 89 тестов unittest: 69 существующих и 20 новых Qt/контроллера; прошли с системным Python и PySide6 6.11.2.
- Ruff E9/F63/F7/F82, git diff --check, проверка ссылок документации и соответствия версий прошли.
- Qt-предпросмотр всех пяти вкладок в обеих темах; отдельные сцены QR, отсутствия привязки, ошибки связи и загрузки.
- Системная тема выбирается и сохраняется; ручное светлое/тёмное оформление проверено.
- Скриншоты компактной формы при QT_SCALE_FACTOR=1.5 и 2. Кнопка сохранения доступна; поля прокручиваются.
- Проверены черновики/выделение/фокус при событиях, отмена опасного действия, переключение маски секрета, ошибки API, queued worker delivery, порт активного подключения и запрет запуска unconfigured worker.
- Проверены Enter и Tab через QtTest. Семантические подписи/checked состояния присутствуют; экранный диктор не проверен.
- Фактический Qt-трей зарегистрирован; закрытие спрятало окно, открытие восстановило его, явный выход вернул управление из QApplication.exec. Bridge в этой проверке не запускался.
- Контраст text/muted/accent/error на фоне light:15.02/6.41/5.18/6.23; dark:16.32/7.41/10.59/10.63.
- Arch-пакет собран и установлен через pacman с сохранением конфигурации и сертификата; установленный launcher успешно выполнил offline preview.
- Windows EXE собран под Wine/Python3.13.7; выполнен безопасный режим preview, получены Qt-скриншоты. Подлинная Windows, автозапуск и инсталляционный rollback на ней не проверены.

## Установка и безопасность

Конфигурация подключения и bridge.crt сравнены по SHA-256 до/после установки; совпали. Публичный отчёт не содержит их хешей, IP, токенов, отпечатков или личных сообщений. Qt ui.json хранит только тему, страницу и размеры окна; секретные черновики не сохраняются.

Локальное включение новой версии отложено до завершения активных задач и очереди через /api/update/prepare с lease. Это отдельный приватный systemd helper, не часть публикуемых исходников. Проверка после перезапуска будет записана в локальный qt-activation.log. Не считать её уже выполненной.
