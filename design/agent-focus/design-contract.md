# Контракт переноса

Цель: единый характер RemoteVibecode APK и Windows/Linux агента, с сохранением функций и desktop-поведения.

## Доказательства

| Источник | Статус | Вывод |
|---|---|---|
| agent/gui.py, dashboard.py, ui_components.py | observed | Tkinter, пять экранов, синяя палитра, существующие операции |
| MainActivity.kt lightPalette/darkPalette | observed | Точные цвета реализованного APK |
| design/apk-focus-20261003/DESIGN.md | provided | Утверждённое направление «Фокус» |
| Ответы пользователя в плане | provided | PySide6 и согласование макетов до реализации |
| Qt desktop компоновка | inferred/proposed | Собственная адаптация, ещё не проверенная в runtime |

## Сохранить / изменить / не копировать

| Источник | Сохранить | Изменить | Не копировать |
|---|---|---|---|
| APK | Палитру, иерархию, свободные списки, иконку | Размеры и навигацию под desktop | Компоновку телефона и чат, которого нет в агенте |
| Агент | Настройку, привязку, обновления, трей, мост | Оболочку, компоненты, Qt UI | Синие панели и вложенные карточки |
| Макеты | Композицию и ритм | Демо-данные на реальное состояние | Подпись «МАКЕТ», fake fingerprint, QR и номер версии |

## Решение

Один desktop «Фокус»: нейтральный фон, тональная навигация и поля, графитовая основная кнопка, зелёные статусы/вторичные действия. Никаких новых возможностей серверной части ради макета.

## Ограничения

Макеты — HTML/SVG, не работающий Qt. Их свойства hover/focus, DPI, accessibility и восстановление пока спецификация. Вёрстка настройки прокручивается, нижнее действие проверять в реализации. Не заявлять «готов» при неготовом соединении. Системная тема Linux может быть неизвестна — светлый fallback. Windows проверка должна быть отделена от Wine.

## Quality gate

- [x] Девять разделов DESIGN.md, реальные источники и границы.
- [x] Все пять вкладок, первый запуск, обе темы.
- [x] QR, пустое устройство, сетевой отказ, скачивание.
- [x] Реальные функции не заменены декоративными элементами.
- [x] Пользователь согласовал макеты.
- [ ] Qt runtime проверен на Windows/Linux и сопоставлен с макетами.
