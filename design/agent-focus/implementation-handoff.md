# Передача реализации

Сначала согласовать index.html и overview-{light,dark}.png; UI пока не переносить.

После согласования:
1. Читать DESIGN.md/контракт, текущий agent/gui.py и функциональные тесты. Не перезаписывать изменения иконки.
2. Выделить контроллер Python из Tk callbacks; Qt Widgets получают состояние/команды, workers доставляют результаты сигналами в main thread. Сохранить launch(config_path, update_ready) и backend.
3. Перенести оболочку и все страницы через общие компоненты/токены, никакой полной пересборки формы при событиях. QtWidgets/QSystemTrayIcon; сохранить поведение закрытия и отсутствие трея.
4. Обновить упаковку Arch/Windows с Qt plugins/лицензиями. Старые Tk/pystray зависимости удалить после завершения.
5. Проверки runtime, темы/DPI/клавиатура/фокус, мок-сервер, безопасные обновления и QR, скриншоты тех же синтетических сцен. Не тестировать разрушительные операции на личных данных.
6. Установить локальный пакет только после idle; не публиковать без отдельного запроса.

Первый Qt артефакт должен доказать целостность оболочки, обе темы и работу с текущим контроллером без перезапуска моста при навигации. Макеты не являются screenshot runtime.
