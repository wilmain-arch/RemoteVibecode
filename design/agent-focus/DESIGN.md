# RemoteVibecode — desktop C «Фокус»

Статус: макеты согласованы пользователем; выполняется реализация Qt. Источник визуальной системы — текущий APK и design/apk-focus-20261003. Изменения подключения не входят в перенос.

## 1. Visual Theme & Atmosphere
Нейтральный монолитный интерфейс. Свободные строки и группы, ограниченные тональные поверхности для главного действия и полей. Material 3 как язык оформления, адаптированный для desktop. Qt Widgets не является библиотекой Material 3: компоненты реализуются по токенам и согласованной спецификации.

## 2. Color
Light: background #F8F9F7, low #F2F4F0, tonal #EBEEEA, text #202321, secondary #565D58, accent #247661, selected #E5F1EA.
Dark: background #141715, low #1A1F1B, tonal #242A25, text #F2F4F1, secondary #A0A8A2, accent #90D4BB, selected #20382E.
Ошибка Light #A7352D / Dark #FFB4AB, всегда с текстом. Основная кнопка графитовая/светлая как primary APK; зелёный — вторичное действие и статус. Тема: система по умолчанию, при неизвестном значении — светлая; выбор хранить отдельно от подключения.

## 3. Typography
Системный sans-serif, Qt logical px: page 28/36 semibold, hero 22/30 semibold, section 18/26 semibold, body 14/22 regular, metadata 13/20 regular, служебная подпись 12/18. Windows системный Segoe UI; Linux системный sans. Моноширинный только пути/адреса/отпечатки. В HTML-прототипе DejaVu Sans для воспроизводимого изображения. Не уменьшать текст при нехватке места.

## 4. Spacing & Grid
Шаги 4/8/12/16/24/32; main 40px по горизонтали и 36px сверху при широком окне, 24px при компактном. Навигация 224px, компактная 72px при ширине <1000. Главный контейнер max 1032px; две колонки 1.2:1 с gap40, только когда main >=850px. Кнопки минимум40px (44px для primary), элементы навигации48px; иконки22px. Минимальное окно800x600, по умолчанию1280x800. Все значения логические, не физические.

## 5. Layout & Composition
Навигация: Обзор, Устройства, Подключение, Настройки, Обновления; маркер доступного обновления. Обзор: заголовок и статус, тональный блок привязки + свободные состояния связи, ниже устройство и адрес. QR только при показе привязки, после привязки блок меняется на телефон и действие перехода. При недоступности Codex показывать ожидание; «Ваш компьютер готов» только при bridge_ready && relay_ready. Устройства: одна фактическая привязка, описание замены, QR. Не добавлять множественные устройства, если backend не предоставляет их. Подключение: адрес, статусы, маршрут. Настройки: оформление, сервер, Codex. Первый запуск: форма подключения без ненужных визуальных шагов. Обновления: статус/версия/действие, затем свободный читаемый changelog. Текст «МАКЕТ» и демо-версия не входят в приложение.

## 6. Components
Радиусы: tonal hero16, inputs/buttons/nav12, segmented14. Без общей рамки каждой секции. Button primary/secondary/destructive, input с label/hint/error, StatusRow, DeviceRow, InlineNotice, Progress, ConfirmDialog. SVG-иконки одного набора с одинаковой толщиной1.6–2px; новая утверждённая иконка приложения и отдельная tray-иконка. QLineEdit для редактирования; selectable labels для адресов; QTextBrowser для заметок с только разрешёнными внешними HTTP(S)-ссылками, без загрузки удалённых ресурсов. Секрет маскирован, кнопка показать/скрыть. Действия недоступны с объяснением, если операция невозможна. Нельзя копировать многоточие демо-отпечатка в настоящую форму.

## 7. Motion & Interaction
Hover tonal, press selected, focus2px accent; Tab по визуальному порядку; Enter активирует выбранное действие, Escape закрывает диалог без опасной операции. Никакой фоновой перерисовки всей страницы с потерей ввода, фокуса и прокрутки. Сохранять размеры окна, страницу, тему; секретные черновики не сохранять на диск. Настройки подключения по существующей валидации; смена сервера сохраняется с существующим уведомлением о перезапуске. Закрытие в трей; отсутствие трея — минимизация. UI отвечает во время сети/загрузок. Установка обновления ждёт задач и очереди.

## 8. Voice & Brand
Русский язык, короткие подписи. Демо relay.example.org, маскированный секрет, синтетический отпечаток; никаких личных IP/токенов. «Привязан» означает привязку, а не доказанный online. Поддерживать только фактические события и состояния backend. Демо QR не подключает устройство.

## 9. Anti-patterns
Нет синих/фиолетовых панелей, градиентов, свечения, декоративных теней, вложенных карточек, пустого квадрата после привязки, копирования заметок релиза, фиктивного последнего посещения, уменьшения текста, перезапуска моста при смене страницы. Не публиковать личные скриншоты. Не выдавать HTML-макет за Qt-приложение. Перед кодом — согласование этих макетов.
