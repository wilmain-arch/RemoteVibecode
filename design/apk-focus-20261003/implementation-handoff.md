# Передача в Compose
Общие токены UiSpace и appTypography; общая UiScreenHeader. Главная шапка адаптивная Row с overflow. ProjectsScreen закрепляет одну кнопку настроек вместо постоянно показанных опций. Прочие экраны наследуют типографику, поля и отступы. Транспорт, модели данных и callback API сохраняются: полная миграция архитектуры не нужна. Состояния сохраняются существующим rememberSaveable; expanded группы дополнительно сохраняются по ID. Макеты остальных сцен сверяются с этим контрактом, случайные артефакты генерации игнорируются.
