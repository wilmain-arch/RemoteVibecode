# Сохранение функций

| Существующая функция | Место в C |
|---|---|
| Копирование/выделение текста и кода | Свободный Markdown, кнопка копирования под ответом; отдельное копирование кода |
| Файловые ссылки чата/Markdown/субагентов | Общий callback перехода к папке; маршрутизация сохранена |
| Изображения/увеличение/скачивание | Встроенное превью → общий полноэкранный просмотрщик |
| Очередь/отмена/корректировка | Панель над вводом и явные сообщения очереди в ленте |
| Модель/усилие | Нижняя строка цельного ввода → лист выбора |
| Проекты/чаты/перемещение/удаление | Меню слева → проекты; существующие подтверждения |
| Субагенты/управление | Меню чата → субагенты → детали/команды |
| Файлы/передача | Папка у ввода → проект/передача |
| Лимиты/сброс с подтверждением | Компактный блок проектов → подробности/существующее подтверждение |
| Темы/ADB/инструкции/обновления | Закреплённые настройки проектов; обновления также в меню чата |
| Привязка | Существующий QR экран при отсутствии связи/привязки |
| Восстановление сети/состояния | Текущие callbacks и saveable состояния; транспорт не меняется |
| Переход вниз/история | Существующая кнопка ленты/загрузка старых сообщений |
